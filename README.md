# MAS Assignment 3 - Problem 1

## Sequential Multi-Agent Formation Control

This repository contains the MATLAB implementation and animation video for
Problem 1 of Multi-Agent Systems Assignment 3.

### Simulation Details

- Number of agents: N = 20
- State space: R^2
- Communication graph: Connected Erdos-Renyi graph G(N,p)
- Formation control strategy: Distributed formation control
- Name: ADITYA

### Formation Sequence

Random initial positions → A → D → I → T → Y → A

The 20 agents start from random initial positions and sequentially move to
positions forming each letter of the name ADITYA.

### Files

- `MAS_Assignment3_Q1.mlx` — MATLAB Live Script containing the simulation code.
- `ADITYA_formation.mp4` — Animation video showing the sequential formation.
